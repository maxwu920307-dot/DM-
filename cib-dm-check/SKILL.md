# 核對 CIB 方案 DM

1. 依保險年齡、性別、保額與繳費年期配對 DM 欄位和建議書。建議書頁碼可能不同，按「投保利益表」、「年度實繳保費」及「商品摘要」定位。只有 DM 的方案列為缺少建議書，推算值標為推算。
2. 讀取 DM 的所有方案欄位。Keynote 可從副本匯出 PDF，或讀取簡報內的表格資料。首頁預覽圖只用於核對該頁。PDF 表格文字擷取若有欄位錯位，回查原頁。
3. 年繳建議書若在 DM 顯示每月金額，以符合繳費方式折扣的年繳保費除以 12，再核對整元顯示。這欄可標「年繳折算每月約」。另有條件的健康管理折扣時，只有 DM 明列採用該折扣且試算條件相符才納入。
4. 若「身價增值」引用祝壽保險金，從投保利益表取整元金額，**直接捨去到萬元小數一位，不做四捨五入**。例如假設祝壽保險金為 456,789 元，DM 應寫 45.6 萬。若欄名指涉不清，註明以祝壽保險金比對，並留意給付時扣除累計應申領保險金的條件。
5. 對照首次罹患癌症（初期）或癌症（輕度）、癌症（重度）、特定癌症（重度）加碼、特定傷病和特定手術。查年度表的起始年度及加碼達上限年度。最高給付用符合條件的重度癌症保險金加上特定癌症加碼上限，並檢查已領初期或輕度保險金的扣除規則。傷病或手術若標了起始年度，以建議書或保單條款核對，查無就列為待確認。
6. 用繁體中文列出實際差異、對應方案、DM 值與建議書或換算值，並指出缺件及待確認的標示。使用者只要求核對時，保留原檔。可分享的技能檔只包含通用流程與虛構範例。
